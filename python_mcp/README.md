# Python MCP Skeleton

This is a simple, incomplete MCP server written in Python that implements a tool to list the services in a PagerDuty account. For the interview prep, feel free to use any portion of this code or write your code from scratch. We recommend using this skeleton.

## Setup to run the sample

The sample code uses the `mcpserver` and `httpx` libraries. You can install these via `pip`.

You can try the sample code by running:

```
python mcp.py
```

You can use the following token that provides example data from the PagerDuty API:

```
Authorization: Token token=y_NbAkKc66ryYTWUXYEu
```

For information about the API documentation, go to: https://developer.pagerduty.com/api-reference/
